And from Shepherd.

      

        
Shepherd is getting a Machines screen backed by cloudsheep: state, jobs and logs, a shell that opens as a herdr pane, and start, stop or extend after you've read the plan.

      

      
Meet Shepherd →

    

  







  

    

      
TunnelsPorts and presets, like novnc for a worker's desktop.

      
Detached jobsStart, follow, cancel. They outlive the connection.

      
ssh-configHost blocks for plain ssh and rsync.

      
Watchherdr notifications for finished jobs and expiring leases.

      
TemplatesTeach it any VM tool with a line per operation.

      
JSON--json on every data command, for your own tools.

      
Passthroughnative runs a provider's own commands.

      
No dependenciesPython's standard library. ssh and rsync for SSH hosts.

    

  







  

    

      
Setup.

      
    
        
  1. Get it on your pathClone it anywhere and link the CLI.
          
    ln -s ~/Work/cloudsheep/bin/cloudsheep ~/.local/bin/cloudsheep
    2. 
        
  2. Describe your machinesinit writes an example to ~/.config/cloudsheep/machines.toml. Uncomment what you use.
          
    cloudsheep init
    3. 
        
  3. Bind it in herdrPaste herdr/keys.toml into your herdr config, then reload.
          
    herdr server reload-config
    4. 
      

      
Needs Python 3.11+. SSH hosts need ssh and rsync; the herdr picker uses fzf and jq. Details in the README.
